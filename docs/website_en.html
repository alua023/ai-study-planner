AI Study Planner

A student answers five Python questions. The system looks past the score to what the student actually knows, then decides what to do next: review the topic or move on, and which exercise to give.

How it works

Four algorithms, one chain

The output of each step is the input of the next, so this is one product and not four unrelated exercises.

Model assumptions

All probabilities and rewards are set by hand, as the assignment allows. They can be changed in the parameter lab below.

AlgorithmInput parameters
BayesP(knows) = 0.40; P(correct | knows) = 0.85; P(correct | doesn't know) = 0.25. An "almost correct" answer counts as incorrect here.
HMMStart (Beginner 0.7, Ready 0.3); transitions B→B 0.7, B→R 0.3, R→B 0.1, R→R 0.9; emissions B (0.5; 0.3; 0.2), R (0.1; 0.3; 0.6) for Wrong, Partial, Correct.
MDPγ = 0.9; V(Beginner) = 0, V(Ready) = 10; rewards: Beginner: Review +4, NextTopic −3; Ready: Review +1, NextTopic +6.
Hill Climbing5 exercises per type; target success 70%; score = 1 − |P(success) − 0.70|.

Data instead of assumptions

Value iteration or Q-learning instead of a single Bellman step, and Simulated Annealing for a large exercise bank.
